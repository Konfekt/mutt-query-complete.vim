1. Introduction                                   *mutt-query-complete-intro*

This plug-in lets Vim complete names and e-mail addresses in a mail buffer by
the mutt address query tool defined by `query_command`, such as abook,
notmuch-addrlookup or mutt_ldap.py. This is particularly useful when editing
e-mails with `mutt` and `$edit_headers` set.

===============================================================================
2. Usage                                          *mutt-query-complete-usage*

Consider editing a mail file in Vim with the following content:
>
    From: Lu Guanqun <guanqun.lu@gmail.com>
    To:   foo
<
Assume your query tool has an entry (address, a tab, then the name):
>
    foo@bar.com	Foo Bar
<
Place the cursor right after `foo` and press CTRL-X CTRL-O (see
|i_CTRL-X_CTRL-O|). The result will be:
>
    From: Lu Guanqun <guanqun.lu@gmail.com>
    To:   "Foo Bar" <foo@bar.com>
<
In a `To:`, `Cc:` or `Bcc:` header line, the text to complete runs from the
previous `,`, `;` or `:` (skipping blanks) to the cursor, so it may contain
blanks. Elsewhere it is the word before the cursor.

3. Setup                                          *mutt-query-complete-setup*

                                                      *g:muttquery_filetypes*
Completion is enabled by default in all mail buffers by setting 'omnifunc'.
To enable it for more file types, set `g:muttquery_filetypes`, which defaults
to `[ 'mail' ]`, before the plug-in is loaded.

                                                        *g:muttquery_command*
By default, the query command is the value of `$query_command` reported by
`neomutt -Q query_command` or `mutt -Q query_command`. If neither is
installed, it is read from the first muttrc found among the usual locations,
such as `~/.config/neomutt/neomuttrc`, `~/.config/mutt/muttrc` and
`~/.muttrc`. To set a command explicitly, add to your vimrc:
>
    let g:muttquery_command = 'mutt_ldap.py %s'
<
As in mutt, the text to complete is shell-quoted and replaces `%s` (quotes
around `%s` are dropped), or is appended if the command contains no `%s`.
If the first word of the command is no executable, an error is shown and
`g:muttquery_command` is set to an empty string.

For different mail accounts with distinct query commands, use a folder hook
in `.muttrc`. For an account `mailo`, add:
>
    folder-hook '~/.local/share/mbsync/mailo/' 'source "$XDG_CONFIG_HOME/mutt/accounts/mailo"'
<
Then, in `"$XDG_CONFIG_HOME/mutt/accounts/mailo"`, tell Vim about it by:
>
    set editor = "vim --cmd 'let g:muttquery_command = \"mutt_ldap.py --config $XDG_CONFIG_HOME/mutt-ldap/mailo.cfg %%s\"'"
<
`--cmd` sets the variable before the mail buffer is opened, and `%%` stands
for a literal `%` in `$editor`.

4. Related                                      *mutt-query-complete-related*

- vim-mutt-aliases (https://github.com/Konfekt/vim-mutt-aliases) completes
  e-mail addresses by those in your mutt alias file.
- vim-notmuch-addrlookup (https://github.com/Konfekt/vim-notmuch-addrlookup)
  completes e-mail addresses by those indexed by notmuch.
